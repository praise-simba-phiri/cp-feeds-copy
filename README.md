# cp-feeds-copy

Full-screen variant of [cp-feeds-mw](https://github.com/praise-simba-phiri/cp-feeds-mw).

The only difference from the original is that this version is edge-to-edge: zero side gutter, no `max-width` cap on the page shell. Every other component, palette token, and animation matches the source.

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.
